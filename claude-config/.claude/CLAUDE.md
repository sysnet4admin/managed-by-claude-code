# 전역 지침 (이 파일은 더 이상 정본이 아니다)

한국어 문체 규칙은 2026-08-10에 별도 비공개 저장소 한 곳으로 통합했다.
`~/.claude/CLAUDE.md` 심링크도 그쪽을 가리킨다. 이 파일은 배관 기록으로만 남긴다.

새 랩탑 설정 시:

```bash
ln -sfn <문체 저장소>/global/CLAUDE.md            ~/.claude/CLAUDE.md
ln -sfn <문체 저장소>/rules/ai-tells.md           ~/.claude/ai-tells.md
ln -sfn <문체 저장소>/rules/assistant-register.md ~/.claude/assistant-register.md
```

이 저장소는 공개다. 비공개 저장소의 이름과 사용자명을 여기에 적지 않는다.
